## Introduction

Welcome to OpenSuite Document Editor, a powerful web-based word processor that brings professional document editing capabilities to your browser. Whether you're writing a simple letter or creating a complex report, OpenSuite has the tools you need.

### Key Features

- **Rich Text Editing**: Full-featured formatting with fonts, colors, styles, and more
- **Real-time Collaboration**: Work together with team members simultaneously
- **Version History**: Track changes and restore previous versions
- **Cloud Storage**: Save documents to Google Drive, OneDrive, or Dropbox
- **Advanced Tools**: Grammar check, spell check, thesaurus, and more
- **Professional Templates**: Start with pre-designed templates
- **Mail Merge**: Create personalized documents from templates
- **Charts & Graphics**: Insert and customize charts
- **Multi-language Support**: Interface available in 7 languages
- **Accessibility**: WCAG 2.1 AA compliant

### System Requirements

**Supported Browsers:**
- Google Chrome 90 or later
- Mozilla Firefox 88 or later
- Safari 14 or later
- Microsoft Edge 90 or later
- Opera 76 or later

**Note:** Internet Explorer is not supported.

**Minimum Hardware:**
- 2 GB RAM
- Modern processor (dual-core or better)
- Stable internet connection (for cloud features)

## Getting Started

### Creating Your First Document

1. **Open OpenSuite**: Navigate to your OpenSuite URL in a supported browser
2. **Create New Document**: Click "New Document" or press `Ctrl+N` (Cmd+N on Mac)
3. **Choose a Template** (Optional): Select from available templates or start blank
4. **Start Editing**: Click anywhere in the document and begin typing

### The Interface

The OpenSuite interface consists of several key areas:

**Menu Bar**: Access file operations, editing tools, and settings
- File, Edit, View, Insert, Format, Tools, Help

**Toolbar**: Quick access to common formatting options
- Font, size, bold, italic, underline, colors, alignment

**Ruler**: Visual guide for margins and indentation
- Drag margin markers to adjust page layout

**Document Area**: Your main editing space
- Click and type to add content
- Use the mouse to select and format text

**Status Bar**: Shows document information
- Word count, page number, language, zoom level

**Comments Panel**: View and manage document comments
- Appears on the right side when comments are present

## Basic Editing

### Typing Text

Simply click anywhere in the document and start typing. The cursor will appear where you clicked, and text will flow naturally as you type.

### Selecting Text

**Using Mouse:**
- Click and drag to select text
- Double-click to select a word
- Triple-click to select a paragraph

**Using Keyboard:**
- `Shift + Arrow keys`: Select character by character
- `Ctrl + Shift + Arrow keys`: Select word by word
- `Ctrl + A`: Select all text

### Moving Text

**Cut and Paste:**
1. Select the text you want to move
2. Press `Ctrl + X` (Cmd + X on Mac) to cut
3. Click where you want to place the text
4. Press `Ctrl + V` (Cmd + V on Mac) to paste

**Drag and Drop:**
1. Select the text
2. Click and hold on the selection
3. Drag to the new location
4. Release the mouse button

### Copying Text

1. Select the text you want to copy
2. Press `Ctrl + C` (Cmd + C on Mac)
3. Click where you want to paste
4. Press `Ctrl + V` (Cmd + V on Mac)

### Undo and Redo

**Undo**: Press `Ctrl + Z` (Cmd + Z on Mac) to undo the last action
**Redo**: Press `Ctrl + Y` (Cmd + Y on Mac) to redo an undone action

You can undo/redo multiple actions by pressing the shortcut repeatedly.

### Deleting Text

- Press `Delete` to remove text after the cursor
- Press `Backspace` to remove text before the cursor
- Select text and press `Delete` or `Backspace` to remove selection

## Formatting Text

### Font and Size

**Change Font:**
1. Select the text you want to format
2. Click the font dropdown in the toolbar
3. Choose a font from the list

**Change Font Size:**
1. Select the text
2. Click the size dropdown or type a size
3. Press Enter to apply

**Common Font Sizes:**
- 10pt: Small text, footnotes
- 12pt: Standard body text
- 14pt: Slightly larger body text
- 18pt: Subheadings
- 24pt: Headings
- 36pt: Titles

### Text Styles

**Bold**: `Ctrl + B` (Cmd + B on Mac)
**Italic**: `Ctrl + I` (Cmd + I on Mac)
**Underline**: `Ctrl + U` (Cmd + U on Mac)
**Strikethrough**: Click the strikethrough button
**Superscript**: Click the superscript button (x²)
**Subscript**: Click the subscript button (x₂)

### Text Color

**Change Text Color:**
1. Select the text
2. Click the text color button (A with color bar)
3. Choose a color from the palette
4. Click "Custom" for more colors

**Change Highlight Color:**
1. Select the text
2. Click the highlight button (marker icon)
3. Choose a highlight color

### Text Alignment

**Align Left**: `Ctrl + L` (Cmd + L on Mac)
**Align Center**: `Ctrl + E` (Cmd + E on Mac)
**Align Right**: `Ctrl + R` (Cmd + R on Mac)
**Justify**: `Ctrl + J` (Cmd + J on Mac)

### Paragraph Formatting

**Line Spacing:**
1. Select the paragraph(s)
2. Click the line spacing button
3. Choose spacing (1.0, 1.15, 1.5, 2.0, etc.)

**Indentation:**
- Increase indent: Click indent button or press `Tab`
- Decrease indent: Click outdent button or press `Shift + Tab`

**Spacing Before/After:**
1. Select paragraph(s)
2. Open Paragraph settings
3. Adjust "Before" and "After" spacing

### Styles

**Apply a Style:**
1. Select the text
2. Click the Styles dropdown
3. Choose a style (Heading 1, Heading 2, Normal, etc.)

**Modify a Style:**
1. Right-click a style in the Styles panel
2. Choose "Modify"
3. Change formatting options
4. Click "OK"

**Create a New Style:**
1. Format text the way you want
2. Select the formatted text
3. Click "New Style" in the Styles panel
4. Name your style and click "OK"

## Working with Images

### Inserting Images

**From Your Computer:**
1. Click Insert > Image > From Computer
2. Browse and select an image file
3. Click "Open"
4. The image appears in your document

**From URL:**
1. Click Insert > Image > From URL
2. Paste the image URL
3. Click "Insert"

**Drag and Drop:**
- Simply drag an image file from your computer into the document

### Resizing Images

**Using Mouse:**
1. Click the image to select it
2. Drag corner handles to resize proportionally
3. Drag side handles to resize in one direction

**Using Size Controls:**
1. Select the image
2. Click the Image Tools tab
3. Enter exact width and height values

### Image Positioning

**Wrap Text:**
1. Select the image
2. Click "Wrap Text" button
3. Choose wrapping style:
   - Square: Text wraps around image
   - Tight: Text wraps closely around image
   - Through: Text wraps through image
   - Top and Bottom: Text above and below
   - Behind Text: Image behind text
   - In Front of Text: Image in front of text

**Align Image:**
1. Select the image
2. Click alignment buttons:
   - Align Left
   - Align Center
   - Align Right

### Image Effects

**Add Border:**
1. Select the image
2. Click "Image Border"
3. Choose border style, color, and width

**Add Shadow:**
1. Select the image
2. Click "Image Effects"
3. Choose a shadow style

**Adjust Brightness/Contrast:**
1. Select the image
2. Click "Corrections"
3. Adjust brightness and contrast sliders

## Tables and Lists

### Creating Tables

**Insert Table:**
1. Click Insert > Table
2. Hover to select number of rows and columns
3. Click to insert

**Alternative Method:**
1. Click Insert > Table > Insert Table
2. Enter number of rows and columns
3. Click "OK"

### Editing Tables

**Add Rows/Columns:**
- Right-click in a cell
- Choose "Insert" > "Rows Above/Below" or "Columns Left/Right"

**Delete Rows/Columns:**
- Right-click in a cell
- Choose "Delete" > "Rows", "Columns", or "Table"

**Merge Cells:**
1. Select multiple cells
2. Right-click and choose "Merge Cells"

**Split Cells:**
1. Right-click in a merged cell
2. Choose "Split Cells"
3. Enter number of rows and columns

### Table Formatting

**Change Borders:**
1. Select the table
2. Click "Table Design" tab
3. Choose border style from "Borders" dropdown

**Apply Table Style:**
1. Select the table
2. Click "Table Design" tab
3. Choose a style from the gallery

**Adjust Column Width:**
- Drag column borders to resize
- Double-click border to auto-fit

### Creating Lists

**Bulleted List:**
1. Click the Bullets button or press `Ctrl + Shift + L`
2. Type your list items
3. Press Enter for each new item

**Numbered List:**
1. Click the Numbering button
2. Type your list items
3. Press Enter for each new item

**Multi-level Lists:**
- Press `Tab` to indent (create sub-list)
- Press `Shift + Tab` to outdent

**Change List Style:**
1. Select the list
2. Click the dropdown arrow next to Bullets or Numbering
3. Choose a different style

## Headers and Footers

### Adding Headers

1. Click Insert > Header
2. Choose a header style or click "Edit Header"
3. Type your header content
4. Click "Close Header and Footer" or double-click in document

### Adding Footers

1. Click Insert > Footer
2. Choose a footer style or click "Edit Footer"
3. Type your footer content
4. Click "Close Header and Footer" or double-click in document

### Page Numbers

**Insert Page Numbers:**
1. Click Insert > Page Number
2. Choose position (Top, Bottom, Margins)
3. Choose style

**Format Page Numbers:**
1. Click Insert > Page Number > Format Page Numbers
2. Choose number format (1, 2, 3 or i, ii, iii or A, B, C)
3. Choose starting number
4. Click "OK"

### Different First Page

To have a different header/footer on the first page:
1. Double-click the header or footer
2. Check "Different First Page"
3. Edit the first page header/footer
4. Close header/footer

### Different Odd and Even Pages

To have different headers/footers for odd and even pages:
1. Double-click the header or footer
2. Check "Different Odd & Even Pages"
3. Edit odd and even page headers/footers
4. Close header/footer

## Page Layout

### Page Size

1. Click Layout > Size
2. Choose a standard size or click "More Paper Sizes"
3. Enter custom width and height if needed
4. Click "OK"

**Common Page Sizes:**
- Letter: 8.5" × 11"
- A4: 210mm × 297mm
- Legal: 8.5" × 14"
- Tabloid: 11" × 17"

### Page Orientation

1. Click Layout > Orientation
2. Choose "Portrait" or "Landscape"

### Margins

1. Click Layout > Margins
2. Choose a preset or click "Custom Margins"
3. Enter margin values for Top, Bottom, Left, Right
4. Click "OK"

**Common Margins:**
- Normal: 1" all sides
- Narrow: 0.5" all sides
- Moderate: 0.75" top/bottom, 1" left/right
- Wide: 1" top/bottom, 1.25" left/right

### Columns

1. Click Layout > Columns
2. Choose number of columns (1, 2, 3, or More)
3. For custom columns, click "More Columns"
4. Adjust width and spacing
5. Click "OK"

### Breaks

**Page Break:**
- Press `Ctrl + Enter` (Cmd + Enter on Mac)
- Or click Insert > Page Break

**Section Break:**
1. Click Layout > Breaks
2. Choose break type:
   - Next Page: New section starts on next page
   - Continuous: New section starts on same page
   - Even Page: New section starts on next even page
   - Odd Page: New section starts on next odd page

## Collaboration Features

### Sharing Documents

**Share with Specific People:**
1. Click the "Share" button
2. Enter email addresses
3. Choose permission level (View, Comment, Edit)
4. Add a message (optional)
5. Click "Send"

**Share with Link:**
1. Click the "Share" button
2. Click "Get Link"
3. Choose access level
4. Copy the link
5. Share the link

### Real-time Collaboration

When multiple people are editing:
- You can see other users' cursors
- Changes appear in real-time
- User names appear next to their changes
- Chat with collaborators using the built-in chat

### Comments

**Add a Comment:**
1. Select text or place cursor
2. Click Insert > Comment or press `Ctrl + Alt + M`
3. Type your comment
4. Click "Post"

**Reply to a Comment:**
1. Click on the comment
2. Type your reply
3. Click "Reply"

**Resolve a Comment:**
1. Click on the comment
2. Click "Resolve"

**Delete a Comment:**
1. Click on the comment
2. Click the delete icon

### Track Changes

**Enable Track Changes:**
1. Click Review > Track Changes
2. Start editing - all changes are tracked

**Review Changes:**
1. Click Review > Next or Previous
2. For each change, choose:
   - Accept: Keep the change
   - Reject: Discard the change

**Show/Hide Markup:**
- Click Review > Show Markup to toggle visibility
- Choose what to show: Comments, Insertions, Deletions, Formatting

### Version History

**View Version History:**
1. Click File > Version History > See Version History
2. Browse through versions
3. Click on a version to preview
4. Click "Restore this version" to revert

**Name a Version:**
1. Open Version History
2. Click the options menu (⋮) next to a version
3. Click "Name this version"
4. Enter a name and click "OK"

## Advanced Features

### Grammar and Spell Check

**Run Spell Check:**
1. Click Review > Spelling & Grammar
2. Review each suggestion
3. Choose: Ignore, Change, Add to Dictionary

**Auto-Correct:**
1. Click File > Options > Proofing > AutoCorrect Options
2. Add custom corrections
3. Enable/disable auto-correct features

**Set Proofing Language:**
1. Select text
2. Click Review > Language > Set Proofing Language
3. Choose language
4. Click "OK"

### Find and Replace

**Find Text:**
1. Press `Ctrl + F` (Cmd + F on Mac)
2. Enter search text
3. Press Enter or click "Find Next"

**Replace Text:**
1. Press `Ctrl + H` (Cmd + H on Mac)
2. Enter text to find
3. Enter replacement text
4. Click "Replace" or "Replace All"

**Advanced Find Options:**
- Match case: Exact uppercase/lowercase match
- Whole words: Match whole words only
- Wildcards: Use special characters for pattern matching

### Mail Merge

**Setup Mail Merge:**
1. Click Mailings > Start Mail Merge
2. Choose document type (Letters, Emails, etc.)
3. Select recipients (Use existing list, Outlook contacts, etc.)
4. Insert merge fields
5. Preview results
6. Finish & Merge

**Insert Merge Fields:**
1. Place cursor where you want the field
2. Click Mailings > Insert Merge Field
3. Choose field from your data source

**Preview Results:**
1. Click Mailings > Preview Results
2. Use navigation buttons to browse records

### Charts

**Insert Chart:**
1. Click Insert > Chart
2. Choose chart type (Column, Line, Pie, etc.)
3. Click "OK"
4. Edit data in the spreadsheet window
5. Close the spreadsheet when done

**Customize Chart:**
1. Click the chart to select it
2. Use Chart Design and Format tabs
3. Change style, colors, layout
4. Add titles, labels, legends

### Table of Contents

**Insert Table of Contents:**
1. Apply heading styles to your headings
2. Place cursor where you want the TOC
3. Click References > Table of Contents
4. Choose a style

**Update Table of Contents:**
1. Right-click the TOC
2. Click "Update Field"
3. Choose "Update page numbers only" or "Update entire table"

### Footnotes and Endnotes

**Insert Footnote:**
1. Place cursor where you want the reference
2. Click References > Insert Footnote
3. Type the footnote text at the bottom of the page

**Insert Endnote:**
1. Place cursor where you want the reference
2. Click References > Insert Endnote
3. Type the endnote text at the end of the document

### Cross-References

**Insert Cross-Reference:**
1. Place cursor where you want the reference
2. Click Insert > Cross-reference
3. Choose reference type (Heading, Bookmark, etc.)
4. Select the item to reference
5. Click "Insert"

### Bookmarks

**Insert Bookmark:**
1. Select text or place cursor
2. Click Insert > Bookmark
3. Enter bookmark name
4. Click "Add"

**Link to Bookmark:**
1. Select text to become the link
2. Click Insert > Hyperlink
3. Choose "Place in This Document"
4. Select the bookmark
5. Click "OK"

## Saving and Exporting

### Save Document

**Save:**
- Press `Ctrl + S` (Cmd + S on Mac)
- Or click File > Save

**Save As:**
- Press `F12` or click File > Save As
- Choose location and filename
- Click "Save"

### Auto-Save

OpenSuite automatically saves your document every 30 seconds when auto-save is enabled. You'll see "Saved" in the status bar.

### Export Options

**Export as DOCX:**
1. Click File > Export > Export as DOCX
2. Choose location
3. Click "Save"

**Export as PDF:**
1. Click File > Export > Export as PDF
2. Choose options (page range, quality, etc.)
3. Click "Save"

**Export as HTML:**
1. Click File > Export > Export as HTML
2. Choose location
3. Click "Save"

**Export as Plain Text:**
1. Click File > Export > Export as Plain Text
2. Choose location
3. Click "Save"

### Print Document

**Print:**
1. Press `Ctrl + P` (Cmd + P on Mac)
2. Choose printer
3. Adjust settings (copies, pages, etc.)
4. Click "Print"

**Print Preview:**
1. Click File > Print Preview
2. Review the document
3. Adjust settings if needed
4. Click "Print" or "Close"

## Troubleshooting

### Document Not Saving

**Problem:** Document won't save
**Solutions:**
- Check internet connection (for cloud storage)
- Verify you have write permissions
- Try saving with a different filename
- Check available disk space
- Try File > Save As to a different location

### Formatting Lost

**Problem:** Formatting disappears when copying/pasting
**Solutions:**
- Use "Paste Special" > "Keep Source Formatting"
- Copy from the same application when possible
- Check if styles are defined in the document
- Try pasting into Notepad first, then reformat

### Slow Performance

**Problem:** Editor is slow or laggy
**Solutions:**
- Close other browser tabs
- Clear browser cache
- Update browser to latest version
- Reduce document size (split large documents)
- Disable browser extensions
- Check system resources (CPU, RAM)

### Images Not Displaying

**Problem:** Images don't show up
**Solutions:**
- Check image file format (JPG, PNG, GIF supported)
- Verify image URL is correct (for web images)
- Check file size (large images may timeout)
- Try re-inserting the image
- Clear browser cache

### Collaboration Issues

**Problem:** Can't see other users' changes
**Solutions:**
- Check internet connection
- Verify document is shared with you
- Refresh the page
- Check if you have edit permissions
- Ask document owner to reshare

### Spell Check Not Working

**Problem:** Spell check doesn't catch errors
**Solutions:**
- Verify proofing language is set correctly
- Check if spell check is enabled
- Add custom words to dictionary
- Try running manual spell check (F7)

### Print Issues

**Problem:** Document doesn't print correctly
**Solutions:**
- Check printer connection
- Update printer drivers
- Try printing as PDF first
- Check page setup and margins
- Verify printer supports document features

### Browser Compatibility

**Problem:** Features don't work in your browser
**Solutions:**
- Update browser to latest version
- Try a different supported browser
- Clear browser cache and cookies
- Disable browser extensions
- Check browser console for errors (F12)

### Data Loss Prevention

**Tips to avoid losing work:**
- Enable auto-save
- Save frequently (Ctrl + S)
- Use version history
- Keep backup copies
- Save to cloud storage
- Check "Saved" status before closing
